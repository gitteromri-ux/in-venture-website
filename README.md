# IN Venture — website

Premium rebuild of in-venture.com. Static site, no build step.

- `index.html` home · `firm.html` · `value-creation.html` · `roadmaps.html` · `portfolio.html` · `team.html` · `insights.html` · `quantum-computing.html` · `position.html` · `contact.html` · `legal.html`
- `css/base.css` design tokens · `css/components.css` components
- `js/data.js` all portfolio, team and nav content (single source of truth)
- `js/site.js` header, footer, dual clocks, command palette, cursor, reveals, counters
- `js/globe.js` Three.js Tel Aviv ⇄ Tokyo globe
- `js/field.js` sector flow-field overlay

All copy and figures are taken verbatim from in-venture.com. Nothing invented.
